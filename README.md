# 洞见 AI
中文消费者洞察与营销策略平台，第一版。静态站点，无付费 AI 接口，无后端上传。

本地运行：`python3 -m http.server 8000 --directory dist`，浏览器访问 localhost:8000。
测试：`npm test`。

## 架构
- `dist/engine.js`：独立规则分析、统计与策略适配层，后续可替换模型服务。
- `dist/app.js`：六页交互、CSV/Excel 解析、原始证据、筛选、HTML 报告。
- `dist/style.css`：响应式品牌视觉。
- `dist/vendor/xlsx.full.min.js`：SheetJS CE 0.20.3（Apache-2.0），本地依赖，无运行时 CDN 请求。

默认展示24条明确标记的美妆护肤模拟评论。支持 UTF-8/GB18030 CSV 与首个非空 Excel 工作表，最大10MB/20000行。首行作为表头，重复列名拒绝。用户选评论与产品列后分析；空评论跳过，重复记录保留。数据仅保存在页面内存，刷新重置。

规则为关键词匹配，多标签计数；情绪分类支持正/负/混合/未识别及部分常见否定。讽刺、长距离否定、复杂语境可能误判，务必人工复核。策略为样本统计驱动的模板建议，不代表因果关系或市场总体结论。

报告支持HTML下载及浏览器打印成PDF；原生PDF、大模型、自动人口画像、账号和云端持久化暂未实现。

## V1.1 词云
消费者洞察新增可按情绪筛选的高频反馈词云；数据看板词云随产品/情绪/需求筛选联动。预设美妆护肤词表逐字扫描、最长短语优先，每条评论每个词只计一次；最多展示20/30/50词，可点击查看原文。文字大小基于评论提及次数，颜色无情绪含义；词云与规则分类统计口径不同，已在界面说明。HTML报告新增前30词频表。

## V1.2 轻量导入
主入口改为粘贴评论与截图识别，文件上传作为折叠批量入口保留。
- 粘贴支持逐行或空行分隔，自动去空白、标记重复和独立时间/界面文字；用户勾选确认后替换分析数据。最多20万字符/2000条预览。
- OCR 使用 Tesseract.js 5.1.1 与 tesseract.js-core 5.1.1、tessdata_fast 简中/英文模型，所有资源随站点托管，图片在浏览器 Web Worker 中识别，不调用付费接口、不上传图片。最多5张、单图10MB、合计20MB；图片适度放大并限制800万像素。
- 识别结果追加到可编辑文本框。OCR不能保证昵称、时间、评论边界或错字识别正确，必须先人工核对，再预览确认。支持停止和超时提示。
- 图像识别与消费者规则分类是不同环节；洞察仍为规则统计，截图OCR不意味着接入了语义分析大模型。

## V1.3 品牌档案与口语反馈
- 品牌/产品/平台/采集日期随每次确认分析保存到浏览器 IndexedDB；每次新建独立记录，刷新恢复最近一次保存。模拟演示不归档。没有账号、云同步，清理网站存储会丢失记录。
- 品牌档案支持筛选、打开旧记录、导出 JSON 备份及导入；相同 ID 不覆盖。对比两批原文时使用同一规则重新分析，显示情绪、需求和痛点的数量、样本占比及百分点变化，提示重复采样；不代表市场趋势。
- 补充 get不到/没get到、大肆营销/营销太大、不经用等短语归并，支持空格大小写变体。关键反馈独立展示并可回溯原文，避免词云前30词掩盖低频问题。成分与渠道咨询保留为疑问，不能作为产品事实。
- 规则仍无法理解所有反讽和复杂上下文；OCR错字、昵称、评论边界需人工核对。历史保存的是核对后的评论，不存截图。

截图识别调整为中文模型优先（模型支持常见拉丁字母），避免简中+英文联合识别将中文长句误读成英文乱码。实际截图回归可提取 get 不到、没 get 到、大肆营销；仍存在错字和界面噪声，不能跳过人工核对。

## 产品图片档案
产品档案按品牌与产品名称归集历史批次。支持独立创建产品，上传/更换 JPG、PNG、WebP 封面和备注；10MB内原图压缩为最长边800px JPEG后存入已有 IndexedDB settings，不改变评论记录。产品卡片显示跨批次评论总量、分析次数、平台及最近采集日期，一键筛选历史与对比。备份包含产品图片，兼容原有无图片备份；同品牌同产品的现有资料导入时保留。封面由用户上传，不预置未经确认的品牌产品图。
